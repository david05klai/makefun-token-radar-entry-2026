Loading model

Observed-token records with positive market cap and TVL train a robust log–log size curve. Expanding-window validation uses only older tracking cohorts to fit each fold and the next cohort to score it. The selection table compares the size curve with a fixed multiple, age and weekly-change terms, and a shrunken category adjustment.
